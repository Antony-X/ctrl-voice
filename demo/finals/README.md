# Finals presentation

Open `index.html` in Chrome (works straight from the file, no server, no internet) and press **F** for fullscreen.

| Key | What it does |
| --- | --- |
| → / Space, ← | Next / previous step |
| F | Fullscreen |
| S | Speaker notes in a second window (with timer) |
| N | Speaker notes over the slide |
| B | Jump to the backup videos |
| X | Skip this slide (remembered in this browser) |
| P | Pause or play the current clip or video |
| R | Replay this slide's animation and audio |
| T | Reset the timer |
| . | Black screen |

To put a recording of a real rehearsal first on the backup slide, save it as `media/video/live_backup.mp4`.

`fig/` holds the scripts that compute the figure data in `media/` from the example audio and engine output.
